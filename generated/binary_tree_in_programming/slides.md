## Which of the following is NOT a property of a binary search tree \(BST\): Core Concept

![Which of the following is NOT a property of a binary search tree \(BST\) Concept](https://picsum.photos/seed/fcce7d346519bbf0a99a60881027ba1c/800/300)

A binary search tree \(BST\) does not need to be a complete binary tree\. The essential properties of a BST are that the left subtree contains only nodes with keys less than the node's key, the right subtree contains only nodes with keys greater than the node's key, and there are no duplicate nodes\.

*Key points to remember:*
- A binary search tree \(BST\) does not need to be a complete binary tree\.
- The essential properties of a BST are that the left subtree contains only nodes with keys less than the node's key, the right subtree contains only nodes with keys greater than the node's key, and there are no duplicate nodes\.
- This concept is fundamental to understanding the topic.

**Question:** What is the maximum number of nodes in a binary tree of height h?

**Correct Answer:** 2^h \- 1

## What is the maximum number of nodes in a binary tree of height h: Core Concept

![What is the maximum number of nodes in a binary tree of height h Concept](https://picsum.photos/seed/ead0dafcecdd3b125fe8f245dcd9e87e/800/300)

The maximum number of nodes in a binary tree of height h is given by the formula 2^h \- 1\. This is because each level i \(0 to h\-1\) can have at most 2^i nodes, and summing these up gives the total maximum nodes\.

*Key points to remember:*
- The maximum number of nodes in a binary tree of height h is given by the formula 2^h \- 1\.
- This is because each level i \(0 to h\-1\) can have at most 2^i nodes, and summing these up gives the total maximum nodes\.

## Understanding: In a complete binary tree, every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible\. What is the height of a complete binary tree with n nodes

![In a complete binary tree, every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible\. What is the height of a complete binary tree with n nodes](https://picsum.photos/seed/ab1b54679a4f483fe6855cd8a67ae3d1/800/300)

**Question:** In a complete binary tree, every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible\. What is the height of a complete binary tree with n nodes?

**Correct Answer:** ceil\(log2\(n \+ 1\)\) \- 1

---

## In a complete binary tree, every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible\. What is the height of a complete binary tree with n nodes: Core Concept

![In a complete binary tree, every level except possibly the last is completely filled, and all nodes in the last level are as far left as possible\. What is the height of a complete binary tree with n nodes Concept](https://picsum.photos/seed/9cc9d2958525c96c59ec821ab0f97db5/800/300)

The height of a complete binary tree with n nodes is ceil\(log2\(n \+ 1\)\) \- 1\. This formula accounts for the fact that the tree is filled from left to right, and the height is determined by the position of the last node\.

*Key points to remember:*
- The height of a complete binary tree with n nodes is ceil\(log2\(n \+ 1\)\) \- 1\.
- This formula accounts for the fact that the tree is filled from left to right, and the height is determined by the position of the last node\.
- This concept is fundamental to understanding the topic.
