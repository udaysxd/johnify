## Which language is statically typed: Core Concept

![Which language is statically typed Concept](https://picsum.photos/seed/7f180e2193c8d91b4c47b1f3c03d47ee/800/300)

Java is statically typed, meaning the type of a variable is known at compile time\. Python is dynamically typed, meaning the type is inferred at runtime\.

*Key points to remember:*
- Java is statically typed, meaning the type of a variable is known at compile time\.
- Python is dynamically typed, meaning the type is inferred at runtime\.
- This concept is fundamental to understanding the topic.
