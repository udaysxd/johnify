## Introduction to Quadratic Equations
- A **quadratic equation** is a polynomial equation of the form:  
  **ax² + bx + c = 0**, where **a**, **b**, and **c** are constants and **a ≠ 0**.
- The graph of a quadratic equation is a **parabola**, which opens upward if **a > 0** and downward if **a < 0**.
- Quadratic equations model real-world scenarios like projectile motion, area problems, and optimization.

## Solving Quadratic Equations: Factoring
- Use when the quadratic expression is factorable.
- Steps:
  1. Write the equation in standard form: ax² + bx + c = 0.
  2. Factor the quadratic expression.
  3. Set each factor equal to zero.
  4. Solve for x.
- Example: x² - 5x + 6 = 0 factors to (x - 2)(x - 3) = 0, so **x = 2 or x = 3**.

It's like solving a puzzle - finding the pieces that fit together perfectly! -->

## Solving Quadratic Equations: Completing the Square
- Steps to complete the square:
  1. Write the equation as ax² + bx = -c.
  2. Divide by a if a ≠ 1: x² + (b/a)x = -c/a.
  3. Add (b/(2a))² to both sides.
  4. Write the left side as a perfect square.
  5. Take the square root of both sides and solve for x.
- Useful for deriving the quadratic formula and graphing.

<!-- NARRATION: Now let's tackle completing the square - a powerful technique that helps us solve any quadratic equation. It might seem tricky at first, but with practice, you'll find it's quite elegant and systematic. -->

## Applications of Quadratic Equations
- Real-world examples:
  - **Projectile motion**: height of an object over time.
  - **Area and perimeter problems**: maximizing area given fixed perimeter.
  - **Economics**: profit maximization and cost minimization.
- Solving these often involves setting up and solving a quadratic equation.
